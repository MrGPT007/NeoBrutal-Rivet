# Third-party notices

Some React primitives in this source-first component collection are based on patterns from the shadcn/ui ecosystem and use open-source dependencies including Radix UI, Base UI, lucide-react, Sonner, Recharts, and others listed in `package.json`.

Retain upstream license notices when redistributing third-party code. Before publishing Rivet as a packaged library, run a dependency/license audit and include all required notices.
