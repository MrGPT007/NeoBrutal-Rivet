# Changelog

All notable project changes are recorded here while NeoBrutal Rivet is in public alpha.

## 0.1.0 — 2026-09-07

### Added

- Independent NeoBrutal Rivet identity and project structure.
- Semantic light/dark/system theming.
- Fluid `clamp()` token scale for type, spacing, controls, radii, and shadows.
- Neo-brutalist component skin and motion language.
- Machine-readable component registry and LLM guidance.
- Initial migrated React primitive source set.
- Static showcase site with dark mode, accent playground, searchable component catalog, LLM workflow, and roadmap.
- GitHub Pages deployment workflow.
- Public-project README, contributing guide, repository metadata recommendations, third-party notices, sitemap, robots file, favicon, and branded 404 page.

### Known work in progress

- Completing and verifying the full source migration for every registered component contract.
- Per-component documentation and state/variant matrices.
- Dependency-backed TypeScript/build verification and visual regression.
- Package publishing and installer tooling.
